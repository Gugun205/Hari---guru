WEBSITE HARI GURU - GUGUN & HIAS

Paket ini sudah berisi 7 foto asli di folder fotos, file musik.mp3, index.html, dan style.css.

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder Website_Hari_Guru_Gugun_Hias di VS Code.
3. Klik kanan index.html lalu pilih Open with Live Server.
4. Klik Buka Surat untuk membuka amplop dan memulai musik.

Catatan: Browser mengizinkan audio mulai setelah interaksi pengguna, sehingga lagu dipicu saat tombol Buka Surat diklik.
